# v0.4.3

This release updates the desktop shell and makes the macOS window easier to drag from the title bar.

## Highlights

- **Updated desktop shell** — Pincer now runs on Electrobun 2. Monitoring, the tray, and your local data work the same way.
- **Clearer macOS title bar** — The area you drag to move the window now follows the title bar, including when the sidebar changes width.

## Notes

Most of this release is internal. Day-to-day monitoring is unchanged.
